Compilador e runtime de referência em Rust

Concorrência com ciclos de vida visíveis.

Lia combina funções finitas, rotinas isoladas e loops persistentes orientados por sinais. Antes de executar, o compilador verifica limites de término e estima a complexidade assintótica.

Aprenda Lia → Execute o primeiro exemplo
main.lia
import std

routine main() {
  spawn Inbox("hello")
}

loop Inbox() {
  std.log(message.value)
  terminate
}

Uma entrada. Uma instância nomeada de loop.

Restrições de projeto

Torne os limites úteis explícitos.

01

Trabalho finito

Funções e rotinas devem terminar. Loops persistentes são verificados uma iteração finita por vez.

02

Tarefas isoladas

Cada tarefa agendada recebe uma arena. Ao terminar, sua arena inteira desaparece de uma vez.

03

Sinais nomeados

Loops possuem caixas postais FIFO. Um sinal nunca espera pelo loop que vai consumi-lo.

A linguagem

Inicie com intenção. Faça spawn com intenção.

Programas começam em routine main(). Arquivos sem ela são bibliotecas. Rotinas são tarefas independentes; funções são as declarações que retornam valores e podem lançar exceções.

  • ✓ Loops for limitados; não há while.
  • ✓ Recursão estrutural para funções finitas.
  • ✓ try/catch em toda parte; throw somente em funções.
Ponto de entrada + fronteira de exceção
import std

routine main() {
  spawn Worker()
}

routine Worker() {
  try { parse("42") }
  catch error { std.log(error) }
}

Modelo de execução

Do arquivo ao trabalho concorrente.

Uma chamada do compilador passa por etapas explícitas. A execução começa somente em routine main(); arquivos sem essa rotina são bibliotecas.

1

Resolver imports

O arquivo declara cada dependência, como import std ou import math.

2

Verificar

O compilador analisa tipos, grafo de chamadas, recursão estrutural e uma iteração de cada loop.

3

Executar

main pode iniciar rotinas com spawn. Cada tarefa recebe uma arena isolada e é liberada ao terminar.

Um programa pequeno e completo
import std

func sum(items: List[Int]) -> Int {
  match items {
    Nil => 0,
    Cons(head, tail) => head + sum(tail)
  }
}

routine main() {
  std.log("total:", sum([2, 3, 5]))
}

Resultado

total: 10

sum é uma função: retorna um valor e reduz a lista de items para tail. Essa redução é a prova de que a recursão termina.

Loops persistentes

Um loop fica dormente até receber spawn.

O primeiro spawn o inicia. Spawns posteriores sinalizam a instância ativa, em vez de reiniciá-la.

1DormenteDeclaração registrada.
→
2Iniciadospawn Inbox(value)
→
3ReagendadoUm sinal por iteração.
→
4Encerradoterminate libera o nome.
import std

routine Producer() {
  spawn Inbox("new work")
}

loop Inbox() {
  std.log(message.value, message.pending)
  terminate
}
// Sem argumento, o loop inicia sem sinal enfileirado.
spawn Inbox()

// Primeira iteração:
message.value   // None
message.pending // 0
